# Obsidian → Fantasy Grounds Story Exporter

Right-click a folder in Obsidian → "Export to Fantasy Grounds" → the
folder becomes a Fantasy Grounds library module (Story book: chapters /
subchapters / pages), including locally embedded images. Re-exporting
updates the same module in place.

Status: design approved, implementation not started.
